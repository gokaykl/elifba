# Elif-Ba

Elif-Ba harflerini, harekeleri ve temel okuma kurallarını adım adım öğreten uygulama.

- **Öğren:** 12 kısa ders, başta/ortada/sonda yazılışlar, seçerek veya yazarak ezber
- **Harfler, Harekeler, Kurallar:** her harfin hareke alınca nasıl okunduğu, 15 temel kural
- **Test:** harf tanıma, harekeli okuma, işaret tanıma

iPhone: sayfayı Safari'de aç → Paylaş → **Ana Ekrana Ekle**.
Android: Chrome'da aç → ⋮ → **Ana ekrana ekle** (ya da ElifBa.apk'yı kur).
